# 商業簿記3級 仕訳練習Webアプリ

商業簿記3級の学習者を対象とした、仕訳問題に特化した反復練習Webアプリケーションです。
Next.js (App Router) と TypeScript を使用し、Vercel 上にデプロイして動作するフルスタック構成で開発されています。

---

## 📌 プロジェクト概要
* **開発目的**: 商業簿記3級で最も重要な「仕訳」の反復演習を効率化し、定着率を向上させる。
* **ターゲット**: 簿記3級の受験生・初学者
* **主な特徴**:
  * 複合仕訳（借方・貸方が複数行になる取引）に対応した5行固定入力インターフェース
  * 入力金額の3桁カンマ自動フォーマット（`100,000`）および右揃え・等幅フォント表示
  * 問題ごとの動的選択肢表示（ひっかけ問題・類似勘定科目の出題）
  * 順序不問の自動正否判定とわかりやすい模範解答・解説
  * 単元別絞り込み、出題数指定（直接入力）、デフォルトランダム出題
  * `localStorage` を活用した誤答データの永続保存と「要復習」集中的演習
  * 認証なしですぐ試せる「ゲストモード」と、将来拡張予定の「ユーザーモード」の2段階設計

## 🚀 主な機能仕様

### 1. トップページ（出題設定・モード管理）
* **単元選択**: 内部API（`/api/categories`）よりカテゴリ一覧を動的取得
* **出題数指定**: 単元の最大問題数に応じた1〜N問の直接入力（デフォルト10問）
* **出題順選択**: ランダムシャッフル機能（デフォルトON）
* **誤答履歴連携**: 過去に間違えた問題が存在する場合、選択肢先頭に「🔥 要復習（N問）」を自動挿入
* **履歴クリア機能**: 誤答履歴が存在する際、「🗑️ 復習履歴をクリア」ボタンより一括初期化

### 2. 演習画面（仕訳入力・判定・解説）
* **5行固定入力レイアウト**: 借方・貸方それぞれ5行の「科目（選択）＋ 金額（入力）」を横並び配置
* **3桁カンマフォーマット**: フォーカスが外れたタイミング（`onBlur`）で `100,000` のように自動整形、編集時（`onFocus`）は数値に戻るユーザー補助
* **自動判定ロジック**: 入力された行の内容（科目と金額のセット）を抽出し、複合仕訳や入力順序に依存しない柔軟な照合
* **即時解説 ＆ 結果表示**: 正否メッセージ、模範解答、詳細解説の表示。全問終了後は正答率・得点・評価メッセージを表示
* **解き直し機能**: 演習直後に間違えた問題だけを即座に再挑戦可能

### 3. データ永続化（ゲストモード）
* **誤答の自動保存**: 解答時に不正解だった問題のIDを `localStorage` に記録
* **自動克服判定**: 「要復習」モードで正解した問題は `localStorage` から自動削除

## 👤 アクセスモード仕様

| モード名 | ログイン | 機能範囲 | データ保存先 |
| :--- | :--- | :--- | :--- |
| **ゲストモード** | 不要 | ・基本出題・自動判定・解説表示<br>・単元別絞り込み・出題数指定・ランダム出題<br>・誤答データの自動保存 ＆ 「要復習」機能 | ブラウザ（`localStorage`） |
| **ユーザーモード** | **要**（予定） | ・クラウド上への学習履歴・正答率の長期保存<br>・複数端末間の進捗自動同期<br>・弱点分析ダッシュボード | 外部データベース（Supabase / PostgreSQL等） |
